# NAT gateway  ·  scenario id: nat-gateway
#
# The ISP server (203.0.113.10) has no route back to your private LAN, so nothing gets a reply. Configure PAT on R1 (`ip nat inside` on the LAN interface, `ip nat outside` on the ISP interface) so PC-A reaches the server through R1's public address.
#
# Loads the scenario, applies the solution, and checks the goal. Paste into
# the command console (the >_ toolbar button) or run with routesim.run(...).

scenario load nat-gateway
cli R1 enable
cli R1 configure terminal
cli R1 interface Ethernet1
cli R1 ip nat inside
cli R1 exit
cli R1 interface Ethernet2
cli R1 ip nat outside
scenario check
