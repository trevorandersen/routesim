# RIP convergence  ·  scenario id: rip-convergence
#
# Three routers in a chain, no routes between the end LANs. Enable RIP on R1, R2, and R3 (advertise each router's connected networks) so PC-A and PC-C can reach each other.

# Loads the scenario, applies the solution, and checks the goal. Paste into
# the command console (the >_ toolbar button) or run with routesim.run(...).
